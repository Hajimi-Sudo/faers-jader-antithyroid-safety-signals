# Data boundary

The public code release contains no FAERS or JADER raw files, no report-level
derived matrix, no patient-level data, and no authentication material. All
data acquisition, preprocessing, signal calculation, and experiment execution
belong on the assigned remote server.

The study uses publicly available FDA FAERS and PMDA JADER resources. The
manuscript reports aggregate reviewed outputs only. Any local copy used for
development must remain documentation-only and must not be used to run the
analysis.
